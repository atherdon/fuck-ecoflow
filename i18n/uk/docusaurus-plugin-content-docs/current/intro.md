# Почати тут

Цей сайт документує польовий зарядний кейс (ящик) для позицій дронарів і розвідників. Ідея — ящик, який можна відкрити й одразу працювати: планшети, акумулятори й кабелі зібрані разом. Його швидше розгорнути й згорнути, а захистити чи евакуювати легше, ніж окрему станцію EcoFlow.

Опублікована документація розміщена на [atherdon.github.io/fuck-ecoflow](https://atherdon.github.io/fuck-ecoflow/).
