# Feedback

If something is hard to find, a link is wrong, or you want to add a note, the best place is a GitHub issue on [atherdon/fuck-ecoflow](https://github.com/atherdon/fuck-ecoflow/issues).

The published site is [atherdon.github.io/fuck-ecoflow](https://atherdon.github.io/fuck-ecoflow/).

## What helps

- The page URL, and what you expected to see
- For a typo or a broken link, the sentence or path that is wrong
- For a new note or photo, where in the sidebar it should live

## If you open a pull request

Please keep changes small, and do not delete historical notes. Media in this repository uses Git LFS. The root [CONTRIBUTING.md](https://github.com/atherdon/fuck-ecoflow/blob/main/CONTRIBUTING.md) file has the current branch and test commands.

Maintainers’ technical notes (APIs, media checks, repository layout) are in the [Maintainers](./maintainers/repository-organization.md) section.
