# 2. Жабка 2.0. TBD

Дууже цікавий прилад, який зараз дуже важко знайти. Це та сама жабка, але окрім тайп сі там є понижайка струму та вихіж хт60. цей пристрій дозволить заряджати рацію від фпв батарейки.

Приклад того як працює єкіпаж вампіра наведений нижче. Але для того щоб у нашої піхоти був зв’язок по рації - вонги мають її заряждати. Для цого їм потрібні павербанки. 

окрім павербанка потрібен кабель з’єднати павер та рацію.

якщо ми робимо такий виріб, де можливо заряджатися від фпв батарейки - ми по смуті можемо відмовитися від павербанка з проводами.

Замість скидати павербанк - у посилку кладеться фпв батарейка, або шось схоже.

Тоді коли ми витягуємо комірки з батарейки фпв - кладемо їх у кейси які купляють голландці на але - ми робимо “дурну” працю - при умові шо у нас таких виробів удосталь
