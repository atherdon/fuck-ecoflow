# How to read this site

This site is a working notebook for a field charging case, not a polished product manual. Pages range from finished write-ups to raw chats and photo galleries.

## Where to start

1. [Start here](./intro.md) — what the project is
2. [Problem statement](./00-Problem/problem-statement.md) — why it exists
3. [Ящик фірми Фізік і друзі](./charging-station/readme.md) — the main charging-station page
4. [Versions](./charging-station/versions/Versions.md) — how the box is meant to evolve
5. [Completed cases](./charging-station/Y-completed-cases/readme.md) — builds that already exist

Use the search box in the header when you are looking for a person, a part, or a case number. [All pages](./pages-index.md) is a full list.

## Languages

Some pages are in Ukrainian, some in English, and some mix both. Use the language switcher in the header to move between English and Ukrainian. Where a translation exists, the same URL is served in the other language; otherwise the original is shown.

## What the main sections are for

- **Problem** — the field situation that the case is meant to improve
- **Charging station** — the main build: versions, completed cases, tasks, notes, and side projects
- **Outsourcing engineering** — related products and partner engineering
- **Team**, **Communication**, **Reports**, **Orders**, and **3D to print** — people, outreach, status, parts lists, and print files
- **Information & notes** (inside Charging station) — background research and conversation records, not the build plan itself
- **Inspiration & side projects** — reference builds, not the main design

## What you may run into

- Copied chats and meeting notes keep the original wording, including informal language
- Some folders still have export-style names or more than one copy of the same note
- A few pages are short placeholders; they are left in place so old links do not break
- Image-heavy case pages are mostly photos, with only a short caption
