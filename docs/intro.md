# Start here

This site documents a field charging case (ящик) for drone and reconnaissance positions. The idea is a box you can open and start working from: tablets, batteries and cables packed together, faster to deploy and tear down, and easier to protect or evacuate than a standalone EcoFlow station.

The published documentation is at [atherdon.github.io/fuck-ecoflow](https://atherdon.github.io/fuck-ecoflow/).
