# Охолодження (чого?)

## Охолодження — складне питання:

- Прямий вихід із кейса небажаний через умови транспортування
- Пропонується: створити фальш-кришку з каналами для повітря, отворами під USB, та входом/виходом для повітря
- Потрібні кулери (бажано тихі)
- Можливе використання контролю температури або фізичної кнопки на фальш-кришки

Проблема: кнопка може не використовуватись, якщо не буде автоматизації

Примітка: можливо Фізик вирішить використовувати пасивне охолодження (алюмінієві радіатори)
