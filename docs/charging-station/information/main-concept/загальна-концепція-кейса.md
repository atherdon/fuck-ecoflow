# **Загальна концепція кейса**

Всі наступні кейси мають бути уніфікованими, це дозволяє краще планувати внутрішнє наповнення (павербанк, батареї тощо). 

<aside>
💡

Один кейс = одна структура. 

Також це робить costs low за рахунок того, що ми будемо замовляти деталі усі оптом.

</aside>

Основна ідея: відкрив кришку кейса — і вже можеш працювати.

Все живлення та пристрої є інтегрованними.

### Базові компоненти, що мають бути у кейсі:

- BMS (**bought the first version**)
- Проводки (**in progress**)
- Секція батарей(**i didnt get it**)
- Плати для роботи павербанку (**here are talking about**)
- Зарядний пристрій (**elaborate more on it**)
