# Frog v1.

### 1. «Жабка»

Моторола николи не думала що їх рації будуть використовуватися таким чином. тому вони зробили вихід для зарядки рації через 220 через “стакан” в який вставляється рація цілком. схоже на те як заряджаються єлектронні зубні щітки. Це не працює. Тому з’явився такий пристрій який є перехідником від рації на type C.

Це даэ змогу нашим хлопцуям заряджати рації від павербанкив. 

Об’єм: 40шт одразу підуть у роботу. такі штуки треба робити постійно. треба замовляти плати заздалегідь закодроном та робити це на постійній основі. якшо накопити запас у 200шт це вже результат на декілька місяців вперед
